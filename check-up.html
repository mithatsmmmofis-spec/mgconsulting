Company check-up

Paste or load a trial balance. The page runs the control set an inspector would run, in the order an inspector runs it, and returns a risk-rated report with the basis for each finding and the evidence that would be requested.

LocalThe file is read in your browser. Nothing is uploaded and nothing leaves this page.
Encrypted connectionThe site is served over HTTPS; traffic is encrypted.
Your data stays on your deviceThe calculation and review tools run in your browser; files loaded are never sent to a server.
No trackingNo advertising or analytics cookies, and no third-party tracking.

Trial balance

Accepts CSV, tab or semicolon separated text: account code, account name, debit, credit. Four-column trial balances with separate balance columns are also read. Turkish and plain number formats are both handled.

Declared figures, optional

Entered figures enable the cross-checks in phase three. Left empty, those checks are reported as not performed.

Load the sample or paste a trial balance, then run the review.

Scope. This is an arithmetical and plausibility review of the records supplied. It is not an audit, not a tax inspection and not an opinion on any specific matter. Findings are indications to be examined, not conclusions.

Data. Parsing and analysis run entirely in the browser. No file is transmitted, stored or retained.
